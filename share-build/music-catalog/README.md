# Music Catalog App

A comprehensive Flask web application for cataloging vinyl records and CDs (~3,000 records capacity). Features intelligent barcode scanning, album cover recognition via Claude Vision, and integration with Discogs metadata.

## Features

### Three Entry Modes
- **Barcode Scanning**: USB scanner support with automatic Discogs metadata lookup
- **Photo Recognition**: Upload album cover photos; Claude Vision identifies artist and title
- **Manual Entry**: Direct form input for complete record details

### Key Features
- Duplicate detection (UPC-based for barcodes, fuzzy matching for photos)
- High-resolution cover art from Discogs or personal photos
- Flexible sorting with 8-shelf organization system
- Collection statistics and analytics
- Review queue for records needing attention
- Duplicate record management
- Full-text search across artist, title, label
- Responsive mobile design (iPhone-optimized)
- Offline browsing support

### Database Schema
- SQLite with 20+ fields per record
- Artist/title sort optimization
- Entry mode tracking (barcode/photo/manual)
- Duplicate flagging with parent record tracking
- Cover art source attribution (Discogs vs own photo)
- Needs-review flagging

## Setup

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Configure Environment
Create `.env` from `.env.example`:
```
DISCOGS_TOKEN=your_token_here
ANTHROPIC_API_KEY=your_key_here
SECRET_KEY=random-string-change-in-production
FLASK_ENV=development
```

Get tokens from:
- **Discogs**: https://www.discogs.com/settings/developers
- **Anthropic**: https://console.anthropic.com/

### 3. Run the App
```bash
python app.py
```

Or use the provided start script:
```bash
./start.sh
```

The app will be available at `http://0.0.0.0:5000`

### 4. Access on Network
From another device on the same network (e.g., iPhone):
```
http://<your-ip>:5000
```

## Architecture

### Backend (Python/Flask)
- **app.py**: Main Flask application with all routes
- **database.py**: SQLite operations, schema, queries
- **discogs.py**: Discogs API integration with rate limiting
- **vision.py**: Claude Vision API integration for image recognition

### Frontend
- **templates/**: HTML5 templates (responsive, Tailwind CSS)
- **static/app.js**: Client-side utilities and interactions
- **static/style.css**: Custom styles and print support

### Data Storage
- **collection.db**: SQLite database (auto-created)
- **covers/**: Local album cover images

## Routes

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/` | Browse collection with search and filtering |
| GET | `/add` | Three-tab entry form (barcode/photo/manual) |
| POST | `/add/barcode` | Barcode scan processing |
| POST | `/add/photo` | Album photo analysis |
| POST | `/add/save` | Save confirmed record |
| GET | `/record/<id>` | View record details |
| GET/POST | `/record/<id>/edit` | Edit record metadata |
| POST | `/record/<id>/delete` | Delete record |
| GET | `/review` | Records flagged for review |
| GET | `/duplicates` | Manage duplicate records |
| POST | `/duplicates/<id>/resolve` | Resolve duplicate |
| GET | `/sort-order` | Sort order generator |
| POST | `/sort-order/generate` | Generate shelf placement |
| GET | `/stats` | Collection statistics |

## API Integrations

### Discogs API
- Barcode/UPC search: `GET /database/search?barcode={upc}`
- Artist/title search: `GET /database/search?artist={artist}&release_title={title}`
- Release details: `GET /releases/{id}` (includes cover art)
- Rate limit: 0.5s delay between requests
- Authentication: `Authorization: Discogs token={token}`

### Claude Vision API
- Model: `claude-haiku-4-5-20251001`
- Image input: base64-encoded JPEG/PNG/GIF/WebP
- Output: JSON with `artist` and `title` fields
- Used for album cover identification

## Database Schema

```sql
CREATE TABLE collection (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    artist TEXT NOT NULL,
    artist_sort TEXT,          -- "Last, First" format
    format TEXT,               -- LP, CD, 45, Box Set, etc.
    year INTEGER,
    label TEXT,
    catalog_number TEXT,
    upc TEXT UNIQUE,           -- Barcode
    cover_art_path TEXT,       -- Relative path to covers/
    genre TEXT,                -- Comma-separated
    discogs_url TEXT,
    discogs_id TEXT,
    shelf_section TEXT,        -- e.g., "Shelf 1"
    needs_review INTEGER,      -- 0 or 1 flag
    entry_mode TEXT,           -- 'barcode', 'photo', 'manual'
    notes TEXT,
    date_added TEXT,           -- ISO timestamp
    sort_order INTEGER,        -- Generated by sort tool
    duplicate_flag INTEGER,    -- 0 or 1
    duplicate_of INTEGER,      -- FK to original record
    cover_source TEXT          -- 'discogs' or 'own_photo'
)
```

## Workflow Examples

### Adding via Barcode
1. Go to `/add` → **Barcode** tab
2. Scanner reads UPC automatically
3. App checks for duplicates
4. Discogs API fetches metadata + cover
5. Review & confirm cover source
6. Save to collection

### Adding via Photo
1. Go to `/add` → **Photo** tab
2. Upload album cover (iPhone camera)
3. Claude Vision identifies artist/title
4. App checks for duplicates
5. Discogs searches for metadata
6. Review & confirm cover
7. Save to collection

### Manual Entry
1. Go to `/add` → **Manual** tab
2. Fill in all fields
3. Optional: upload cover photo
4. Save to collection

### Organizing Collection
1. Go to `/sort-order`
2. Click "Generate Sort Order"
3. Algorithm creates numbered list by artist
4. Print guide shows target shelf positions
5. System updates sort_order and shelf_section

## Performance Notes

- SQLite suitable for ~10,000 records
- Discogs API rate limited (0.5s delay)
- Cover images cached locally
- Grid rendering optimized with CSS Grid
- Search/filter is client-side (fast, 0 lag)
- Database indexes on artist, title, format, UPC

## Error Handling

- Graceful fallback when Discogs unavailable
- Photo identification failures show manual entry
- Missing cover art shows placeholder
- Invalid file uploads rejected at client & server
- Offline mode: browsing works, adding requires network

## Security

- CSRF protection via Flask session
- SQL injection prevented with parameterized queries
- File upload validation (image types only)
- No API keys stored in code (environment variables)
- File paths secured with `secure_filename()`
- UPC treated as unique constraint

## Troubleshooting

### "No module named anthropic"
```bash
pip install -r requirements.txt
```

### "DISCOGS_TOKEN not set"
Create `.env` with your token (see Setup section)

### "Port 5000 already in use"
Change port in app.py: `app.run(port=5001)`

### "Cover art not saving"
Ensure `covers/` directory is writable: `chmod 755 covers/`

### "Database locked"
Close app, delete `collection.db-journal`, restart
